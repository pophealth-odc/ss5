    First-time setup

    1. Install the extension in Edge: open edge://extensions, turn on Developer mode, choose Load unpacked, and select the extension folder from this project.
    2. Put this page's address in the extension's manifest.json (externally_connectable → matches), then press Reload on the extension. This page's address is .
    3. Reload this page. The indicator at the top should say Extension connected.
    4. Check the Settings, add your pages above, then press Open Login Page.
