Off by default. Only turn this on for internal test sites; HTTP traffic is not encrypted.

Off by default - the login page is only used to sign in.

If your session expires mid-run, the run pauses and waits for you to sign in and confirm again.

Browser

Microsoft Edge only. The window is always maximised when automation starts. If Edge refuses, you will see a warning instead of a silent failure.

100%

50% to 200% in 5% steps. Applied at the start of the run and re-applied after every page loads. Your own zoom levels in Edge are put back afterwards.

Edge resets zoom when you move to another site, so leave this on unless every page is on one site.

Page loading delay

Delay after a page loads

After Edge reports the page loaded, the tool waits this long before the screenshot, so charts and lazy content can appear.

A page that never finishes loading is marked as failed after this long instead of freezing the run.
